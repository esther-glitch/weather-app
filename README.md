# 🌦️ Weather App

This is a simple weather app created using Python.  
It displays the current temperature, wind speed, and weather condition with emojis.  
It also includes a graphical user interface (GUI) version using `tkinter`.

## 📦 Requirements

- Python 3.x
- `requests` library (install using `pip install requests`)
